# 汤小丹《操作系统原理》第1章「操作系统引论」知识点调研

## 背景

汤小丹等编著的《计算机操作系统》（第四版/慕课版）是国内高校操作系统课程最广泛使用的教材之一。第1章「操作系统引论」是全书的纲领性章节，为后续各章（进程管理、内存管理、文件系统、I/O 管理等）提供概念基础和方法论铺垫。

## 核心发现

### 一、操作系统的定义

操作系统（Operating System, OS）是配置在计算机硬件上的第一层软件，是对硬件系统的首次扩充。其主要作用是管理硬件设备、提高利用率和系统吞吐量，并为用户和应用程序提供简单的接口。

**关键概念**：裸机（bare machine）——未配置任何软件的计算机。OS 是覆盖在裸机之上的最基础系统软件。

---

### 二、OS 的目标与作用

#### 2.1 四大目标

| 目标 | 说明 |
|------|------|
| **方便性** | 用户可通过编译命令将高级语言程序翻译为机器码，无需直接操作硬件 |
| **有效性** | ① 提高系统资源利用率；② 提高系统吞吐量 |
| **可扩充性** | 能方便地添加新功能/模块，修改原有功能/模块 |
| **开放性** | 遵循国际标准（如 POSIX），使不同厂商的软硬件彼此兼容 |

#### 2.2 三大作用

1. **作为用户与计算机硬件系统之间的接口**
   - OS 处于用户与硬件之间，用户通过 OS 使用硬件
   - 三种使用方式：**命令方式**、**系统调用**、**图形/窗口方式**

2. **作为计算机系统资源的管理者**
   - 四类资源：处理机、存储器、I/O 设备、信息（数据和程序）
   - 对应四大管理功能：处理机管理、存储器管理、设备管理、文件管理

3. **实现了对计算机资源的抽象**
   - OS 是铺设于硬件上的多层软件集合
   - 隐藏硬件操作细节，提供多层次的抽象模型
   - 例如：文件是对磁盘 I/O 的抽象，进程是对 CPU/内存的抽象

---

### 三、推动操作系统发展的主要动力

1. 不断提高计算机资源的利用率
2. 方便用户使用
3. 器件的不断更新换代
4. 计算机体系结构的不断发展
5. 不断提出新的应用需求

---

### 四、操作系统的发展过程 ★（重点）

按时间和技术演进顺序：

| 阶段 | 核心特征 | 关键点 |
|------|----------|--------|
| **1. 无操作系统（人工操作）** | 人工操作方式、独占全机 | 用户独占、资源利用率极低、"人机矛盾" |
| **2. 脱机输入/输出** | 外围机 + 磁带 | 解决人机速度不匹配，减少 CPU 空闲等待 |
| **3. 单道批处理系统** | 监督程序（Monitor）、内存中仅一道程序 | 自动成批处理，但 CPU 等待 I/O 时空闲 |
| **4. 多道批处理系统** | 内存中同时驻留多道程序、CPU 与 I/O 并行 | 引入中断技术；资源利用率大幅提高；但无交互能力 |
| **5. 分时系统** | 时间片轮转、多终端、人机交互 | 及时性（响应时间）、独立性、多路性、交互性 |
| **6. 实时系统** | 对外部事件快速响应 | 实时时钟管理、高可靠性、硬实时 vs 软实时 |
| **7. 微机操作系统** | 单用户单任务 → 多用户多任务 | CP/M → DOS → Windows/macOS/Linux |
| **8. 其他** | 网络 OS、分布式 OS、嵌入式 OS | 通信、资源共享、并行计算、低功耗 |

---

### 五、操作系统的基本特性 ★（核心重点）

操作系统共同具有 **并发、共享、虚拟、异步** 四个基本特性。

#### 5.1 并发（Concurrence）

| 概念 | 定义 |
|------|------|
| **并行（Parallel）** | 两个或多个事件在**同一时刻**同时发生 |
| **并发（Concurrent）** | 两个或多个事件在**同一时间间隔**内发生；宏观上同时，微观上交替执行 |

**核心思想**：

- 正是程序能并发执行，才使 OS 能有效提高资源利用率和系统吞吐量
- **进程（Process）** 的引入是实现并发的基础——只有为每个程序建立进程后，它们才能并发执行

#### 5.2 共享（Sharing）

共享是指系统中的资源可供内存中多个并发执行的进程共同使用。

两种共享方式：

- **互斥共享**：资源在一段时间内只允许一个进程访问（如打印机、临界资源）
- **同时访问**：资源在一段时间内允许多个进程"同时"访问（如磁盘、可重入代码）

**并发与共享的关系**：互为存在条件——资源共享以进程并发执行为条件；并发执行以资源共享为条件。

#### 5.3 虚拟（Virtual）

通过某种技术将一个物理实体变为若干个逻辑上的对应物。

- **时分复用技术**：如虚拟处理机（多道程序使每个用户感觉独占 CPU）
- **空分复用技术**：如虚拟存储器（逻辑上扩充内存容量）

#### 5.4 异步（Asynchronism）

- 多道程序环境下，进程以"走走停停"的方式执行
- 每个进程以不可预知的速度向前推进
- 但 OS 需保证：只要运行环境相同，多次运行应获得完全相同的结果

### 六、操作系统的运行环境 ★

#### 6.1 硬件支持

- CPU、内存、中断机制、时钟等硬件构成 OS 运行的物质基础

#### 6.2 操作系统内核

现代 OS 将不同功能设置在**不同层次**中，这些层次统称为 OS 内核。

**目的**：

1. 便于对软件进行保护，防止遭受应用程序破坏
2. 提高 OS 的运行效率

**内核两大功能分类**：

| 分类 | 包含内容 |
|------|----------|
| **支撑功能** | 中断处理、时钟管理、原语管理 |
| **资源管理功能** | 进程管理、存储器管理、设备管理 |

#### 6.3 处理机的双重工作模式 ★

| 模式 | 模式位 | 说明 |
|------|--------|------|
| **内核态（管态）** | 0 | 执行特权指令，可访问所有资源 |
| **用户态（目态）** | 1 | 执行非特权指令，只能访问受限资源 |

- **特权指令**：只能在内核态下运行的指令（如 I/O 指令、中断屏蔽、修改模式位等）
- **非特权指令**：用户态即可运行的指令

#### 6.4 中断与异常 ★

**操作系统是由中断驱动的**——OS 总是在等待某个事件的发生，事件由中断或异常引起。

| 类型 | 引发源 | 示例 |
|------|--------|------|
| **中断（Interrupt）** | 硬件（外部事件） | I/O 完成、时钟信号 |
| **异常/陷阱（Trap）** | 软件（当前指令） | 除数为 0、无效内存访问、系统调用请求 |

---

### 七、操作系统的主要功能 ★（五大管理）

| 功能模块 | 主要任务 | 核心内容 |
|----------|----------|----------|
| **处理机管理** | 以进程为基本单位分配和控制 CPU | 进程控制、进程同步、进程通信、调度 |
| **存储器管理** | 为多道程序提供良好运行环境、提高内存利用率 | 内存分配与回收、内存保护、地址映射、内存扩充 |
| **设备管理** | 完成 I/O 请求，提高 CPU 与 I/O 设备利用率 | 缓冲管理、设备分配、设备处理 |
| **文件管理** | 对用户文件和系统文件进行管理，保证安全性 | 文件存储空间管理、目录管理、文件读写与保护 |
| **接口管理** | 提供用户使用 OS 的方式 | **用户接口**（命令、图形） + **程序接口**（系统调用） |

---

### 八、操作系统的结构 ★

| 结构类型 | 特点 | 优缺点 |
|----------|------|--------|
| **简单结构** | 早期开发，内部复杂混乱，无结构 | — |
| **模块化结构** | 按功能分模块 | 接口难以完全满足需求、无序模块化 |
| **分层式结构** | 自底向上分层，每层仅依赖下层 | 结构清晰、易调试、但效率较低 |
| **微内核结构** | OS 分为微内核 + 多个服务器 | 可靠性高、可扩展性好，但通信开销大 |
| **外核结构** | 内核不提供进程/虚拟存储等抽象 | 只做物理资源隔离与复用，应用层自定义抽象 |

---

### 九、系统调用 ★

#### 9.1 基本概念

- 程序接口是 OS 专门为用户程序设置的，是**用户程序取得 OS 服务的唯一途径**
- 程序接口由一组**系统调用（System Call）** 组成
- 系统调用通过**访管指令**（陷入指令）从用户态切换到内核态

#### 9.2 系统调用的主要类型

| 类型 | 说明 |
|------|------|
| **进程控制** | 创建/终止进程、等待、加载执行等 |
| **文件操纵** | 创建/打开/读/写/关闭文件等 |
| **设备管理** | 请求/释放设备、读/写设备等 |
| **信息维护** | 获取/设置时间日期、系统数据等 |
| **通信** | 建立/断开连接、发送/接收消息等 |

#### 9.3 系统调用与系统程序的区别

- **系统调用**：由 OS 内核提供的底层接口，运行在内核态
- **系统程序**：运行在用户态的工具程序（如编译器、Shell、编辑器等）
